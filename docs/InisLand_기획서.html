목재 드랍과 UI 획득 연출

  • 나무 HP가 0이 되면 목재를 즉시 저장소에 더하지 않고 목재 묶음 아이템을 바닥에 드랍한다. 기존 나무의 수량과 제재소 보너스를 묶음 수량에 반영하며, 같은 나무에서 중복 드랍하지 않는다. 다른 자원의 기존 채집 지급 방식은 유지한다.
  • 묶음은 짧게 튀어 오른 뒤 바닥에서 떠 있는 모습과 목재 ×수량 이름표로 표시한다. 기존 이미지젠 목재 PNG를 월드 아이템과 UI 이동 연출에 함께 사용한다. 나무가 제거돼도 묶음은 별도 오브젝트로 남는다.
  • 드랍 후 0.35초가 지나고 살아 있는 플레이어가 1.1 월드 단위 이내에 오면 자동으로 먹는다. 획득한 목재 아이콘은 화면에서 0.55초 동안 곡선을 그리며 현재 좌상단 목재 아이콘의 중심으로 날아간다. 화면 비율·크기 변경 시에도 공통 자원 레이아웃의 목적지를 사용한다.
  • UI에 도착할 때 실제 목재 수량을 증가시키고 획득음을 재생한다. 목재 아이콘이 살짝 커졌다 돌아오며 숫자가 금색으로 반응하고 +획득량이 표시된다. 게임 정지 중에는 줍기와 이동 연출·수량 지급도 정지한다.
  • 보관함이 가득 차면 묶음을 바닥에 유지한다. 이동 중 다른 획득으로 빈 공간이 줄어도 도착 시 수용 가능한 수량만 지급하고 나머지는 다시 바닥에 남긴다. 중복 획득 요청은 무시하며, 이미 먹은 연출이 정상 씬 정리로 끊기면 남은 수용량을 한 번만 정산한다.
  • 드랍은 현재 씬의 월드 아이템이다. 기존 저장 파일의 범위를 바꾸거나 바닥 아이템 저장 시스템을 새로 추가하지는 않는다.

레퍼런스 비율에 맞춘 HUD 크기

  • 사용자가 첨부한 레퍼런스의 작은 좌상단 프로필·우상단 목표, 좌하단 이동 패드와 우하단 큰 주 행동 버튼 비율을 기준으로 상시 HUD를 조정했다. 기존 이미지젠 PNG 스킨을 유지하고 레이아웃·내부 여백·글자·클릭 영역을 함께 바꿨다.
  • 1280×720 논리 좌표 기준 프로필 330×88→248×76, 자원 줄 536×42→456×36, 목표 330×156→264×134, 시계 240×70→188×44, 이동 패드 164→144, 메뉴 실제 버튼 60→48.
  • 우측 보조 버튼은 60→54, 작업 90→76, 자동 출입 표시 74→60으로 줄였다. 주 공격 버튼은 108→120으로 키우고 그림 크기도 늘려 주 행동과 보조 행동의 위계를 분명히 했다. 버튼 간격은 최소 6, 우측/하단 여백은 16을 사용한다.
  • 프로필의 초상화·이름·HP·XP와 목표 3개 행을 새 패널 안에 맞췄다. 자원 수량 글자는 20→18, 아이콘은 32→28. 자원 줄의 표시 높이는 36이지만 클릭·터치 영역은 44로 유지한다. 보조 원형 버튼은 54 이상, 동료 태세 버튼은 44 높이를 유지한다.
  • 동료/상황 요약은 330×128→248×96으로 줄이고 자원 줄 아래에 배치한다. 권장 행동과 최대 4명의 체력은 G/동료 버튼으로 펼쳤을 때 표시한다(248×220). 압축된 영역에 맞춰 상황·위험 문구를 짧은 한글로 표시한다. 내부 공용 안내 모델의 규칙은 바꾸지 않는다.
  • 메뉴·동료 버튼·요약 패널·자원 줄의 입력 판정을 그리는 레이아웃과 같은 정의에 연결했다. 이동 패드의 유효 반경과 손잡이 이동량도 크기에 맞췄다. PC와 터치의 공통 배율을 유지하며 16:9와 울트라와이드에서 화면 중앙의 플레이 영역을 가리지 않도록 한다.
  • 건설 선택 창·튜토리얼 같은 집중 조작 창은 글자와 터치 조작성 때문에 기존 크기를 유지한다. 자동 출입·정지 건설 모드·벌목과 행동 상태의 기능은 유지한다.

간결한 자원 HUD

  • 사용자가 첨부한 마비노기 모바일 화면의 프로필 아래 작은 아이콘·굵은 수량 배치를 기준으로 자원 HUD를 재구성했다. 기존 330×148 대형 보관 카드와 이름·최대량의 상시 표시를 제거하고, 캐릭터 정보 아래 536×42 한 줄에 5종 아이콘·수량을 표시한다.
  • 목재·석재·고기·식량·서리꽃의 새로운 손그림 PNG 아이콘 5종을 이미지젠으로 만들었다. 투명 아틀라스 2172×724를 원본 바이트 그대로 적용하고, UV와 비율 유지 렌더링으로 각 아이콘을 표시한다. 금속 버튼 테두리 대신 자원 물체 자체의 실루엣을 사용한다.
  • 수량은 굵은 흰색 20px 글자와 어두운 그림자로 표시한다. 한도에 도달하면 금색으로 바뀐다. 1,000 미만은 정확한 정수, 그 이상은 K/M으로 짧게 표시하되 실제 보유량보다 크게 반올림하지 않는다.
  • 자원 줄을 클릭·터치하면 이름·정확한 수량·보관 한도를 담은 상세 창을 연다. 다시 누르거나 바깥을 누르면 닫는다. 상세 창은 일반 HUD를 가리지 않는 옆 공간에 표시하고 월드 클릭과 구분한다. 자원 확인만으로 세계 시간을 정지하지 않는다.
  • PC·모바일이 같은 배율과 배치를 쓴다. 기존 버튼·벌목·자동 출입·건설 모드는 유지한다. 상단 표시의 세로 공간은 148에서 42로 줄였다.

이미지젠 PNG UI 스킨

  • built-in image_gen으로 게임용 투명 PNG UI를 생성해 런타임에 적용했다. 에메랄드 청록색 에나멜·샴페인 금속 테두리·크림색 입체 아이콘·작은 잎 장식으로 구성한다.
  • buttons.png는 4×3 아틀라스(1448×1086)다. 검·활·망치·작업 손·문·자동·메뉴·동료 아이콘 8종, 이동 패드·패드 손잡이, 빈 청록/금색 원형을 포함한다. 기능 아이콘과 이동 패드가 PNG 아틀라스를 사용한다.
  • panel.png(1448×1086)는 상태·자원·목표·건설·메뉴 등 공통 패널의 바탕과 장식이다. pill.png(2172×724)는 긴 버튼의 바탕이다. UV 영역과 9분할 렌더링으로 테두리와 모서리를 유지하며 크기를 조절한다.
  • PNG는 생성 원본 바이트를 그대로 복사했다. 잘라내기·재채색 같은 이미지 편집 없이 Unity UV와 렌더링 설정으로 배치한다. 투명 알파·Bilinear 필터·비압축·4096 최대 텍스처 크기를 적용했다.
  • 글자·키 안내·자원 수량·체력 수치는 선명한 한글 폰트로 실시간 표시한다. 상태별 밝기와 선택 강조를 유지하고, 원형 버튼의 아이콘과 기능 이름을 분리해 겹침을 줄였다. 클릭 영역·키 매핑·건설 정지·벌목 상태·자동 출입 기능은 유지한다.
  • 생성 이미지가 정상 로드되면 기존 도형 아이콘·버튼·패널의 그림 대신 PNG 스킨을 쓴다. 작은 라벨 배경·바·선택 강조와 이미지 누락 폴백은 기존 그리기 코드를 사용한다. SVG 파일은 새로 만들지 않는다.

주인공 행동 상태와 벌목

  • PlayerActionState를 주인공에 연결해 Idle/Move/Attack/Logging/Gather/Dead 중 하나의 상태만 활성화한다. 공격·벌목·채집·사망은 이동과 다른 행동을 차단한다. 공격 입력이 없는 자동 전투가 벌목을 중단하거나 시작하지 않는다.
  • 벌목 시작 시 나무를 향해 좌우로 반전하고 몸을 정지시킨다. Start에서 도끼를 준비하고, Loop의 도끼 타격 프레임에서 나무에 대미지를 준다. 종료·중단 시 End를 재생한 뒤 대기 상태로 돌아간다. 이동 입력은 작업 중단을 요청하며 End 종료 뒤 이동한다. E/중단 버튼으로도 종료할 수 있다.
  • 나무에 TreeHealth(기본 HP 100)를 추가하고, 타격마다 기본 25 HP를 감소시킨다. Loop 주기는 기존 채집 시간의 1/4를 기준으로 하며 동료·도구 보너스는 추가 대미지/동료 타격으로 반영한다. 나무 체력바와 화면 하단 작업 상태/나무 HP를 표시한다.
  • 나무 HP가 0이 되면 기존 설정의 목재 보상을 한 번만 지급하고 기존 규칙대로 나무를 제거한다. 중단 후 남은 체력은 유지된다. 동료도 나무에 시간 간격을 두고 대미지를 주며, 기존 즉시 채집 경로로 온전한 나무를 제거할 수 없다.
  • 붉은 머리 소녀 벌목용 투명 PNG 4×3, 12 프레임을 새로 생성했다. 1행 Start, 2행 Loop, 3행 End. PNG 원본을 수정하지 않고 Unity importer에서 셀과 발 피벗을 설정했다.
  • 주인공 대기·이동·공격·벌목·일반 채집·사망에 각각 Start/Loop/End 클립을 구성했다. 도끼/활 2세트 총 36개 클립, Animator 18개 행동/단계 상태와 연결했다. 벌목은 두 무기 모두 도끼 모션을 쓰며, 나머지 행동은 기존 도끼/활 프레임을 단계별로 나눠 재사용한다. 새로 그린 모션은 벌목이며 다른 등장인물의 애니메이션은 변경하지 않는다.
  • 건설 모드에 들어가면 현재 작업을 중단하고 게임 정지를 유지한다. 기존 자동 출입문과 건설 선택·설치 모드는 유지한다. 사망 모션은 게임 정지 중에도 Start/Loop/End를 마칠 수 있도록 비스케일 시간으로 재생한다.

정지 상태에서 건물 설치

  • 건설 버튼, B, 3을 누르면 즉시 세계 시간을 정지하고 건설 선택 화면을 연다. 건물을 고른 뒤에도 정지 상태를 유지하며 마우스·터치 위치에 선택한 건물의 반투명 미리보기를 보여준다.
  • 건설 모드에서는 일반 이동·공격·작업 입력을 차단하지만 건물 선택·월드 배치·취소는 계속 받는다. 메뉴·룬·튜토리얼의 정지 처리와 분리해 비활성 모달이 건설 정지를 풀지 않도록 했다.
  • 땅을 눌러 설치를 확정하면 그때 자원을 차감하고 기존 ConstructionSite를 생성한다. 건설 모드를 종료하고 이전 게임 속도로 복귀한다. 이후 건설 진행 시간·동료 작업 방식은 기존 규칙을 유지한다.
  • ESC, 우클릭, 취소/건설 종료 버튼, 근접·활 전환으로 취소하면 자원 차감 없이 종료한다. 건물 선택 창 닫기도 게임 진행을 재개한다. 씬 종료 시 건설 정지가 남지 않도록 해제한다.
  • 건설 선택 화면에 게임 정지를 명시하고 배치 안내도 설치·취소 중심으로 바꿨다.

출입문 자동 개폐

  • 플레이어가 문 콜라이더에서 2.2 월드 단위 이내로 접근하면 입력 없이 자동으로 연다. 3.2 단위 밖으로 멀어진 뒤 0.8초 후 자동으로 닫는다. 문 앞에서 왕복해도 상태가 흔들리지 않도록 열림/닫힘 거리를 다르게 사용한다.
  • 열린 문은 플레이어와 동료만 통과한다. 적·동물의 문 충돌은 유지하며 적의 접근은 문을 열지 않는다. 동료가 문 바로 안에 남아 있으면 닫힘을 기다린다.
  • F 수동 토글과 E 작업 목록의 문 열기·닫기를 제거했다. HUD 문 표시는 누르는 기능 대신 자동 출입/출입 가능 상태를 보여준다. 튜토리얼·조작 안내도 자동 출입으로 바꾼다.
  • 일시정지 중에는 문 상태를 바꾸지 않으며 사망한 플레이어의 접근으로 문을 열지 않는다.

공격 버튼으로 나무 벌목

  • 화면 공격 버튼·모바일 터치·Space에 같은 수동 행동 경로를 적용했다. 전투 대상이 없을 때 나무 밑동 콜라이더에서 2.2 월드 단위 이내면 즉시 기존 벌목 진행을 시작한다. 완료 시간·목재 수량은 기존 설정을 유지한다.
  • 공격 사거리 안에 살아 있는 적·동물이 있으면 공격을 우선한다. 공격 쿨다운 중에도 전투 대상을 나무로 바꾸지 않는다. 자동 공격은 벌목을 시작하지 않는다.
  • 같은 나무에서 공격 버튼을 다시 눌러도 채집 진행률은 초기화하지 않는다. 일시정지·메뉴·사망·건설 모드에서는 수동 행동을 막는다. 돌과 발견 지점은 이 벌목 단축 입력의 대상에서 제외한다.

기본 야간 적 4족 로봇

  • 일반 야간 웨이브의 기본 적을 낮은 금속 몸체와 네 개의 기계 다리가 있는 로봇으로 교체했다. 오른쪽 측면에 약간 위에서 본 시점이며 붉은 센서와 낡은 금속 색상을 유지한다.

## 2026-10-17 건물별 연구 업그레이드

울타리 기본 최대 체력은 40이다. 건물 수와 울타리 개별 레벨의 자동 배율을 제거하고 목공소 연구로 40 → 60 → 80 → 100 → 120이 된다. 목공소 건설만으로 체력이 오르지 않는다.

| 분류 | 필요한 건물 | 연구 | 단계당 효과 | 1단계 비용(목재/석재) |
|---|---|---|---|---|
| 방어 | 목공소 | 울타리 보강 | 모든 울타리 최대 HP +20 | 12 / 6 |
| 전투 | 훈련소 | 동료 전투 훈련 | 동료 공격력 +10% | 12 / 5 |
| 생산 | 제재소 | 벌목 기술 | 목재 획득량 +15% | 14 / 8 |
| 농업 | 종자 창고 | 수확 기술 | 작물 수확량 +15% | 8 / 2 |
| 탐색 | 초소 | 야간 정찰 | 초소 시야 반경 +0.5 | 9 / 6 |
| 보관 | 식량 창고 | 식량 보관 확장 | 식량 보관 한도 +40 | 10 / 3 |
| 지원 | 교회 | 마음 돌보기 | 사기 손실 완화 확률 +5%p | 12 / 6 |

각 연구는 독립적으로 0~4단계다. 2/3/4단계 비용은 1단계의 2/3/4배이며, 효과는 기존 시설 효과에 가산한다. 같은 연구를 여러 건물에서 중복 구입하지 않는다. 수확·채집의 실제 획득량은 기존 정수 반올림을 따른다. 초소 시야·교회 사기 효과는 해당 시설이 살아 있을 때 적용된다.

사용: 건설이 완료된 해당 건물 3.5칸 이내에서 ‘연구 · 건물별 업그레이드’ 또는 작업 E로 목록을 연다. 전체 목록은 ESC 메뉴의 ‘연구 목록’에서도 열 수 있다. 미건설/거리/자원 부족/최대 단계를 표시하고 해당 건물 근처에서만 구매한다. 목록이 열린 동안 게임을 멈추고 닫으면 이전 속도로 복구한다.

연구 단계는 GameSession과 기존 세이브에 별도 보관한다. 이전 세이브는 0단계로 시작하며 구매 직후 저장한다. 건물이 파괴돼도 완료 단계는 남고, 추가 연구에는 해당 건물을 다시 지어야 한다. 기존 일반 시설 강화와 연구 진행도는 분리한다. 울타리 직접 강화는 목공소 연구로 대체한다.

## 2026-10-17 연구 10단계 확장

7종 건물별 연구의 최대 단계를 4 → 10으로 확장했다. 기존 연구 단계와 저장은 그대로 이어진다. 필요 건물, 단계당 효과, 비용 공식(기본 비용 × 다음 단계)은 유지한다. 후반 비용이 목재·석재 보관 한도를 넘으면 ‘창고 확장 필요’를 표시한다. 창고를 건설하면 보관 한도가 늘어난다.

울타리 체력: 기본40 / 1단계60 / 2단계80 / 3단계100 / 4단계120 / 5단계140 / 6단계160 / 7단계180 / 8단계200 / 9단계220 / 10단계240.

10단계 누적 연구 효과: 동료 공격력 +100%, 목재/작물 획득량 각각 +150%, 초소 반경 +5, 식량 보관 +400, 사기 손실 완화 확률 +50%p(시설 효과 합산 후 최대100%). 기존 시설 효과에 더해진다.

10단계 단일 비용(목재/석재): 목공소120/60, 훈련소120/50, 제재소140/80, 종자창고80/20, 초소90/60, 식량창고100/30, 교회120/60. 예: 기본100 보관 한도라면 창고1개의 +50으로 모든 연구의 10단계 비용을 보관할 수 있다.

## 2026-10-17 연구 재료 · 사냥/채굴 드랍

광석(Ore)을 실제 자원으로 추가했다. 기존 자원 enum 순서를 보존하고 마지막에 추가했으며, 보유량·보관 한도100·세이브·연구 결제·HUD에 연결했다. 자원 UI는 윗줄 목재/석재/광석, 아랫줄 고기/식량/서리꽃이다. 자원 상세창도 6개 행을 표시한다.

연구 재료: 목재와 석재는 기존 비용을 유지한다. 1~2단계는 광석 없이 진행하고, 3~10단계에는 각각 광석 1/2/3/4/5/6/7/8개를 추가로 요구한다. 광석이 부족하면 다른 재료도 차감하지 않는다. 광석은 이전 세이브에서 0으로 시작한다.

사냥: 살아 있는 동물은 채집으로 바로 보상받을 수 없다. 처치 시 기존 고기 수량을 바닥에 드랍하고, 드랍 실패로0개가 예정된 동물도 최소1개를 드랍한다. 중복 피격/채집으로 중복 보상되지 않는다. 기본 기존 눈토끼 보너스 등은 유지한다.

근접/원거리 구분

근접 무기는 실제 중심 거리 판정과 일치하는 사거리 링을 표시하고 적중 시 밝아진다. 생존한 로봇/동물은 약 0.8칸, 0.18초 동안 물리 충돌을 따르며 밀리고 그동안 추격/공격을 멈춘다. 활은 기존 투사체 피해만 주며 근접 사거리 링과 밀어내기를 적용하지 않는다. 콜라이더 외곽만 사거리 안에 들어온 적을 실제 사거리 밖에서 공격하지 않도록 판정을 일치시킨다.

이동 공격

근접/활 공격 중에도 이동·방향 전환·정지를 정상 속도로 즉시 반영한다. 공격 시작 시 이동 속도를 초기화하지 않는다. 공격 Start/Loop/End 상태와 공격 방향은 유지하며 완료 시 최신 이동 입력에 따라 이동/대기로 복귀한다. 공격 중 벌목/채집 및 무기 전환의 중복 실행 금지와 작업/사망의 이동 잠금은 유지한다.

숲 밀도와 동료 가독성

나무 생성 확률을 실제 씬 50%에서 16%로 줄이고 코드 기본값도 일치시킨다. 야외 영입 후보 확률은 4%에서 8%로 올린다. 동료가 적을 때 낮 후보 등장 간격은 12초에서 6초로 줄이며 마을 중심 3.2~4.2칸의 건물/자원과 겹치지 않는 위치에 등장한다. 마을 후보 상한은 반경 12칸의 실제 영입 가능한 인물만 세어 먼 후보 때문에 도착이 막히지 않게 한다. 주인공·영입 후보·동료를 덮는 나무는 불투명도 28%로 부드럽게 바뀌고 인물이 벗어나면 복구한다. 밤 대피 및 영입 인원 무제한 규칙은 유지한다.

자동 출입 버튼 제거

모바일/PC 공통 HUD의 자동 출입/출입 가능 버튼과 접근 키 표시를 제거한다. 해당 터치 슬롯과 초기 안내의 출입 문구도 제거한다. 실제 문은 기존처럼 플레이어/동료가 가까이 가면 열리고 멀어지면 닫히며 출입에 별도 입력은 필요 없다.

매 리소스 적용

소환 매가 스프라이트를 할당하지 않고 삼각형 ColorFallback만 사용하던 문제를 수정했다. image_gen으로 생성한 투명 PNG Assets/Resources/Sprites/Pets/hawk.png를 SpriteBank.HawkPet 및 Pet.Spawn(Hawk)에 연결한다. 원래 깃털색을 유지하도록 흰색 렌더 틴트를 쓰고 이동 방향에 따라 좌우 반전한다. 소환 단계/전투 수치는 변경하지 않는다.

바닥 빈 영역 수정

현재 씬의 바닥은 고정 50×50 단색 눈 스프라이트여서 이동하거나 넓은 시야에서 경계 밖 배경이 드러났다. GroundCoverage가 카메라 최종 위치를 따라 바닥을 배치하고 직교 카메라 크기/화면 비율에 맞춰 8칸 여유를 포함해 화면을 덮도록 한다. 기존 눈 색상/자원/건물/월드 위치는 유지한다. 양수·음수 좌표, 청크 경계, 16:9·20:9·4:3 및 확대 시야의 화면 모서리 피복을 검증한다.

보스전 밤 유지

보스 예고 및 생존 보스가 있을 때 밤→새벽 전환을 막는다. 정기 보스와 처치 수 기반 보스 모두 적용한다. 밤 타이머는 만료 시 0에 머물고 HUD에 보스전을 표시하며 초과 시간이 이후 페이즈로 넘어가지 않는다. 보스를 잡으면 만료된 밤은 즉시 새벽으로, 시간이 남았으면 기존 밤 시간대로 진행한다. 씬 종료 시 전환 제한 콜백을 해제하고 밤 강제 종료 시 보스 예고 코루틴도 취소한다.
