# Snowfield (6_IL) — 한국어 스토어 설명

## 짧은 설명 (80자 이내)
새벽엔 사냥꾼, 밤엔 성주. 설원에서 마을을 세워라 — 죽은 동료는 돌아오지 않는다.

---

## 긴 설명

**설원에서 살아남아라. 마을을 키워라. 죽은 자는 잊지 마라.**

Snowfield는 낮/밤 사이클이 있는 판타지 중세 마을 생존 게임입니다. 뱀서바이벌의 자동 전투 장관과 퍼마데스의 무게감, 마을 건설의 보람을 결합했습니다. 새벽마다 설원으로 나가 탐험하고, 해 지면 쌓아 올린 것을 지킵니다.

**낮 사이클 — 사냥꾼**
아침이 밝으면 파티를 이끌고 설원으로 출발하세요. 방랑자를 영입하고, 거대한 설원 동물을 사냥하고, 해가 지기 전에 자원을 가지고 귀환하세요. 안개가 먼 곳을 가립니다. 너무 깊이 들어가면 돌아오지 못할 수도 있습니다.

**밤 사이클 — 성주**
해가 지면 언데드가 몰려옵니다. 그리드에 바리케이드를 배치하고, 동료를 포진시키고, 자동 전투가 펼쳐지는 것을 지켜보세요. 당신의 역할은 배치, 장비, 그리고 어디까지 버틸지 판단하는 것입니다.

**마을은 영속한다. 동료는 그렇지 않다.**
지은 건물은 런이 끝나도 남습니다 — 매 생존의 흔적. 하지만 동료가 죽으면 영원히 사라집니다. 누구를 성벽 밖으로 데리고 갈지가 진짜 결정이 됩니다.

**대설보**
드물고, 파국적이고, 예고 없이 옵니다. 대설보가 몰아칠 때는 언데드 물결과 극한의 추위가 동시에 닥칩니다. 모닥불 밖은 지속 대미지. 지금까지 쌓은 모든 것이 한꺼번에 시험받습니다.

**주요 특징**
- 낮/밤 사이클 — 탐험 단계와 방어 단계가 교차
- 런을 넘어 영속하는 마을 성장
- 동료 퍼마데스 — 잃음에 무게가 있다
- 자동 전투 + 전략적 유닛/바리케이드 배치
- 희귀 대설보 이벤트 — 모든 위협이 동시에 몰아친다
- ECS 기반 구조로 수천 개의 엔티티를 동시 처리
