## 심사 진행 경로

### Steam (itch.io 배포 후)
Steamworks 파트너 대시보드 → 스토어 페이지 → 기본 정보 → "IARC 등급 설문" 클릭 → 위 표대로 응답

### Google Play
Play Console → 앱 콘텐츠 → 연령 등급 → 설문지 시작 → 카테고리: 게임  
폭력: 경미한 만화적 폭력 / 공포: 경미 → 저장 → **예상: 12세**

### App Store
App Store Connect → 앱 정보 → 연령 등급  
- 공포/공포감: 경미 → **예상: 12+**

### GRB (한국 게임물관리위원회)
한국 마켓 출시 시 필수. game.or.kr에서 자체등급분류 신청 또는 오픈마켓 제출.  
- 인터넷게임이 아닌 경우 자체등급분류 가능 (12세 이용가 예상)
