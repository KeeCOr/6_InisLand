## 2026-09-21 확정 핵심 방향

**한 줄 정의:** 눈 벌판을 탐사해 생존자와 자원을 데려오고, 난방권과 마을을 확장하며 끝없는 겨울을 버티는 설원 생존 경영 게임.

**코어 루프:** `설원 탐사 → 생존자·자원 귀환 → 난방망 확장 → 주거·생산·방어 건설 → 인구·소비 증가 → 더 먼 설원 개척`.

- 추위는 피해 수치 하나가 아니라 온도 단계, 난방 범위, 연료, 작업 효율, 주민 건강을 연결한다.
- 밤 전투의 목표는 처치 수가 아니라 주민·식량·연료·난방 시설을 지켜 다음 날을 맞는 것이다.
- 마을 확장은 안전지대가 실제로 넓어지는 공간 변화로 표현하고, 확장할수록 소비와 위험도 함께 증가한다.
- 출시 기준은 첫 3일 안에 야영지가 마을로 변하고, 성장의 대가로 다음 날의 부담이 늘어나는 것을 이해하는 것이다.

> "끝없는 겨울. 마지막 마을의 마지막 수호자."

**장르:** 뱀서바이벌 + 낮/밤 베이스 디펜스 + 탑다운 생존
**버전:** v0.3.0 · 2026-07-01
**스택:** Unity 2D + C# + Resources SpriteBank + Windows Standalone

---

## 1. 문제 정의

"혼자서도 짧은 세션 안에 생존과 경영 두 재미를 모두 느낄 수 있는 게임이 없다."
낮에는 설원 탐험가, 밤에는 마을 수호자 — 두 역할이 하나의 세션 안에서 자연스럽게 전환된다.

---

## 2. 페르소나

**주 페르소나**: 이진혁, 27세, 직장인
- 자투리 시간(20~30분)에 게임. 긴 세션 불가.
- 로그라이크/생존류 좋아하지만 복잡한 조작은 부담.
- "오늘 밤은 버텼다"는 성취감을 원한다.

---

## 3. 코어 루프

```
낮(40s) → 설원 탐험 · 나무/돌/고기 채집 · 동물 사냥 · 동료 영입
   ↓ 저녁 자동 텔레포트
밤(40s) → 좀비 웨이브 격퇴 · 모닥불 방어 · 바리케이드 사수
   ↓ 새벽 회복: HP 복구 · 건물 +25%HP · NPC 1명 스폰
낮(다음 레벨)...
```

레벨 스케일: 낮/밤 페이즈 길이 = 40s × (1 + 0.25 × (레벨-1))

## 4. 주요 시스템

### 낮 페이즈
- **이동**: WASD, 설원 맵 자유 탐험
- **채집**: 나무(W), 돌(R), 사슴 사냥(공격)
- **영입**: 떠돌이 NPC 발견 시 대화로 동료 추가 (마을 House 수 한도)

### 밤 페이즈
- **좀비 웨이브**: 무한 증가, 25킬마다 보스 등장
- **보스 스프라이트**: `Assets/Resources/Sprites/Enemies/boss_frost_zombie.png`는 64x64 RGBA 단일 스프라이트로, 첫 보스 밤의 서리 좀비 보스에 사용
- **모닥불**: 2.5u DPS 화상 오라 + 마을 온도 유지 (연료 100s)
- **바리케이드**: 건물 HP 소진 시 마을 함락

### 건물 (10종)
| 건물 | 역할 | 비용 |
|-----|------|------|
| 🔥 Campfire | 좀비 화상 오라 + 온도 유지 | 5W |
| 🏠 House | 인구 한도 +4 | 6W |
| 🏹 Watchtower | 야간 자동 사격 | 8W+4S |
| 🌾 Farm | 식량 생산 | 6W |
| 📦 Storage | 자원 캡 +50 | 8W |
| 🥕 Fence | 외곽 차단 | 1W |

### 동료/NPC 타입
아이(빠름·약함·비전투), 노인(느림·농사+5), 사냥꾼, 치유사, 무사

### UI/HUD 목표 안내
- 좌측 하단 웨이브/스탠스 패널은 `OBJECTIVE → RISK → ACTION` 3개 슬롯을 고정 우선순위로 표시한다.
- 밤, 눈보라, 식량 부족처럼 판단이 필요한 상황은 RISK 슬롯을 위험/주의 톤으로 강조하고, ACTION 슬롯은 바로 수행 가능한 행동 문장으로 제한한다.
- 목표 판단 우선순위는 `난방 중단 → 야간 웨이브 → 주간 식량 부족 → 주간 탐사`다. 식량 부족 상태로 밤에 진입해도 즉시 생존 행동인 바리케이드 복귀가 먼저 표시된다.
- 같은 HUD 패널 안에서 목표 안내, 인구, 동료 스탠스 버튼이 겹치지 않도록 300x118 고정 영역을 사용한다.

#### 2026-09-21 목표 화면 분해

- **예시 화면:** `docs/design-references/2026-09-21-night-objective-priority.png`
- **레이아웃:** 게임 월드를 주 화면으로 유지하고 좌측 하단 안전 영역에 목표 패널, 상단에 자원/시간을 둔다.
- **재사용 컴포넌트:** 기존 `OBJECTIVE`, `RISK`, `ACTION` 3슬롯과 `DailyObjectiveAdvisor` 결과를 사용한다.
- **데이터:** 식량, 동료 수, 마을 난방 여부, 밤 여부. 판단기는 가장 긴급한 상태 하나만 반환한다.
- **상호작용:** 패널 자체는 읽기 전용이며 ACTION 문장이 플레이어의 다음 이동·채집·방어 행동으로 이어진다.
- **상태:** 기본은 외곽 탐사, 빈 동료 상태는 식량 부족을 만들지 않음, 야간은 식량 부족보다 우선, 난방 중단은 모든 상태보다 우선한다. 로딩·오류 상태는 로컬 동기식 계산이라 적용되지 않는다.
- **긴 텍스트/좁은 화면:** 한 슬롯은 한 행동 문장으로 제한하고, 실제 HUD 연결 시 300×118 영역의 줄바꿈과 16:9 최소 지원 해상도를 확인한다.

연구 재료: 목재와 석재는 기존 비용을 유지한다. 1~2단계는 광석 없이 진행하고, 3~10단계에는 각각 광석 1/2/3/4/5/6/7/8개를 추가로 요구한다. 광석이 부족하면 다른 재료도 차감하지 않는다. 광석은 이전 세이브에서 0으로 시작한다.

사냥: 살아 있는 동물은 채집으로 바로 보상받을 수 없다. 처치 시 기존 고기 수량을 바닥에 드랍하고, 드랍 실패로0개가 예정된 동물도 최소1개를 드랍한다. 중복 피격/채집으로 중복 보상되지 않는다. 기본 기존 눈토끼 보너스 등은 유지한다.

채굴: 자연 바위 채굴 완료 시 기존 석재 보상에 더해10% 확률로 광석1개가 바닥에 드랍된다. 탐험 보상 장소는 이 확률 판정에서 제외한다. 확률은 BalanceConfig.RockOreDropChance로 조절한다.

획득: 목재와 동일한 공통 동작을 고기/광석에 확장했다. 바닥 착지 후 주인공1.1칸 이내 접근 시 자동 획득하고0.55초 동안 해당 자원 HUD로 날아간 뒤 실제 수량을 더한다. 보관 한도가 차면 바닥에 남는다. 이동 중 한도가 바뀌어도 남은 수량을 보존한다. 일시정지 중 획득/비행은 정지한다.

## 2026-10-17 대장간 광석 탐사 연구

8번째 건물별 연구로 대장간의 ‘광석 탐사’를 추가했다. 대장간을 건설한 뒤 근처에서 연구 목록을 열고 진행한다. 1단계 비용은 목재12·석재6이며 다음 단계마다 이 기본 비용에 단계 수를 곱한다. 이 연구는 모든 단계에서 광석을 요구하지 않으므로 광석이0개여도 시작할 수 있다.

연구 완료마다 광석5개를 즉시 지급하고 바위 광석 드랍 확률을 +2%p 올린다. 총10단계로 연구 보상은 총50개, 기본 드랍 확률10% 기준 최종30%가 된다. 연구 보상은 지상 드랍이 아니라 보유 자원에 직접 적립하고, 연구 단계와 함께 즉시 저장한다.

광석을5개 보관할 공간이 없으면 ‘광석 공간 부족’을 표시하며 연구 단계와 다른 재료를 소비하지 않는다. 최고 단계에서는 추가 결제·지급하지 않는다. 같은 연구를 다른 대장간에서 중복 적용하지 않는다.

기존7종 연구 ID를 유지하고 끝에 새 항목을 추가했다. 이전 저장의 연구 단계는 그대로 유지하고 광석 탐사만0단계로 시작한다. 연구 목록을8개 행에 맞춰 높이와 간격을 조정하고 기존 PNG UI를 재사용했다.


## 2026-10-17 동료 등장 · 자원 생성 연구

건물별 연구를 총10종으로 확장했다. 추가 연구도 각각10단계이며 완료한 단계는 저장한다.

| 건물 | 연구 | 단계당 효과 | 1단계 목재/석재 |
|---|---|---|---|
| 거처 | 동료 소문 확산 | 영입 NPC 등장 확률·마을 방문 빈도 +10%(기본값 기준 가산) | 8 / 3 |
| 창고 | 자원 분포 조사 | 나무·바위 생성 확률 +10%(기본값 기준 가산) | 10 / 4 |

10단계는 배율2배다. 예시 기본 설정에서는 NPC 확률4%→8%, 나무22%→44%, 바위8%→16%가 된다. 동료 마을 방문의 기본30초 간격은15초로, 동료 부족 시12초 간격은6초로 줄어든다. NPC 동시 생존 상한과 낮에만 생성하는 조건은 유지하므로 NPC가 이미 상한에 도달한 경우 새 NPC가 추가되지 않는다. 기존 영입/거처 수용 인원 조건도 그대로다.

자원 분포 조사는 현재 화면의 나무·바위를 즉시 늘리지 않는다. 새로 생성·재생성되는 청크의 나무·바위 슬롯 확률을 높인다. 나무1개에서 얻는 목재는 기존 제재소 ‘벌목 기술’ 연구가 담당한다. 생성 확률 총합이1을 넘으면 동료·동물 슬롯을 먼저 확보한 뒤 나무·바위를 비례 조정하여 동료 연구가 자원 증가 때문에 무효화되지 않게 한다.

필요 건물 근처(3.5칸)에서 작업E 또는 연구 목록으로 진행한다. 비용은 기본 비용×다음 단계이며 기존 규칙대로3~10단계에 광석1~8개를 요구한다. 이전8종 연구 ID를 유지한 채 뒤에2종을 추가해 이전 저장에서는 새 연구만0단계가 된다.

연구 UI는 한 페이지6종씩2페이지로 나눴다. 이전/다음 버튼을 제공하며, 건물 근처에서 열면 해당 건물의 연구가 있는 페이지를 먼저 표시한다. 기존 생성 PNG 패널과 버튼을 재사용했다.

작업 우선순위 보정: 손상된 건물에서는 수리/연료 보충이 연구 열기보다 먼저 선택된다. 연구는 별도 연구 버튼으로도 열 수 있다.
