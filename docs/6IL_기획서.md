## 2. 한 줄 비전

눈보라 치는 판타지 설원, 낮에는 사냥꾼 · 밤에는 마을 방어자. 영속으로 쌓이는 마을과 잃으면 돌아오지 않는 동료들 사이에서, 얼마나 오래 버틸 수 있는가.

---

## 3. 4가지 게임플레이 기둥

1. **낮의 사냥꾼** — 제한 시간 내 설원 탐험. 동료 영입, 자원 수집, 거대동물 사냥. 시야/안개가 긴장감을 만들고, 대담함과 귀환 타이밍을 저울질.
2. **밤의 성주** — 모닥불로 불빛을 밝히고 그리드에 바리게이트를 깔고, 영입한 동료들과 함께 좀비 무리를 새벽까지 막아냄. 뱀서류의 자동 공격 + 타워디펜스의 전략 배치.
3. **영속하는 마을, 잃어버리는 동료들** — 마을은 계속 성장(영속). 하지만 동료는 영구 사망. 한 번 죽으면 돌아오지 않음 → "누구를 밖에 데리고 갈지"에 무게감.
4. **아주 드문 초대형 눈보라** — 밤의 확장 이벤트. 좀비 + 극한 추위 동시. 모닥불 반경 밖은 지속 대미지. 모든 시스템이 교차하는 절정.

## 4. 타깃 플레이어 여정

| 구간 | 경험 |
|------|------|
| Day 1~5 | 생존 학습 |
| Day 10~30 | 마을 안정화, 동료 누적 |
| Day 50+ | 장비 빌드 실험, 최고 기록 경신 |

- **종료 조건**: 전멸(마을 궤멸)만. 엔딩 없음 (무한 서바이벌).
- **전멸 시**: 점수 기록 + 일부 메타 해금 → 새 마을 시작.

## 5. 기술 스택

| 계층 | 선택 | 역할 |
|------|------|------|
| 게임 엔진 | Phaser 3 | 2D 렌더, 씬 관리, 입력 |
| 언어 | TypeScript (strict) | 타입 안전, 리팩토링 안정성 |
| 빌드 | Vite | HMR, 번들링 |
| ECS | bitecs (후보) | 수천 엔티티 성능 |
| 맵 에디터 | Tiled | 타일맵·콜리전·스폰 포인트 |
| 저장 | localStorage (웹) / 파일 (Tauri) | 마을 영속 데이터 |
| 오디오 | Howler.js 또는 Phaser 내장 | BGM/SFX |
| 에셋 | TexturePacker (무료) / free-tex-packer | 스프라이트 아틀라스 |
| 모바일 | Capacitor v7 | iOS/Android 래퍼 |
| 데스크톱 | Tauri (예정) | Steam 빌드용 (~5MB) |

**Unity 포트**: Unity 2022.3.62f3 포트가 존재하나 현재 기능 구현도 ~15% (WASD 이동 + 채집 + OnGUI HUD 수준). 장기 로드맵. **Phaser 버전이 1차 구현 기준.**

## 7. 핵심 루프 — 낮/밤 사이클

```
하루(One Day) = 낮(8~10분) → 저녁 전환(30초) → 밤(5~7분) → 새벽 전환(30초)
```

| 단계 | 플레이어 주요 행동 |
|------|-----------------|
| **낮** | 설원 탐험·동료 영입·사냥·자원 수집. 귀환 타이밍 선택. |
| **저녁 전환** | 종탑 종소리. 자동 귀환. 바리게이트/건물 재배치 가능. |
| **밤** | 좀비 웨이브 방어. 새벽까지 생존. |
| **새벽 전환** | 좀비 잔당 소멸, 시체 자원 회수, 다음 날 준비. |

---

## 8. 낮 — 설원 (Snowfield)

### 8.1 플레이어 목표 (비강제)

- 자원 수집 (나무, 돌, 약초, 고기)
- 동료 영입 (설원 NPC에게 F키로 말 걸기)
- 거대동물 사냥 → 고기·가죽·희귀 재료
- 룬/축복 아이템 획득 (해당 밤에만 유효)

### 8.2 설원 구역화

| 구역 | 내용 |
|------|------|
| **근교** (반경 1) | 사슴·토끼 + 기본 자원. 안전. Day 1~3 주 구역. |
| **중경** (반경 2) | 늑대 무리, 더 많은 자원, 룬 조각. Day 4~6+. |
| **심경** (반경 3+) | 서리 정령·트롤, 철 광맥, 거대동물(보스급), 희귀 룬. Day 8+ 도전. |

### 8.3 시야 시스템

- 플레이어 중심 원형 시야 (~10타일)
- 밖: 반투명 회색 안개 + 희미한 실루엣
- 지나간 지역: 옅은 "기억" 레이어 (구조물 O, 동적 오브젝트 X)
- 높은 지형/망루로 시야 확장

### 8.4 귀환 타임아웃

- 종 울림 후 설원에 남아 있으면 밤이 설원에서 시작 → 안전 지대 없음
- "야외 밤 생존" 페널티 도전 모드: 살아 돌아오면 희귀 보상

## 9. 밤 — 마을 방어 (Village Defense)

### 9.1 전투 구성

| 요소 | 내용 |
|------|------|
| **좀비 웨이브** | 밤 동안 3~5개 파동, 외곽 2~4 스폰 포인트 |
| **플레이어** | 수동 조작 + 뱀서류식 자동 공격 (장비/룬 기반) |
| **동료** | AI, 배치 지점 반경 방어 또는 플레이어 추종 |
| **모닥불** | 반경 내 지속 화염 DPS + 시야 + 동료 공격력 버프 |
| **바리게이트** | 좀비 이동 차단, 공격 유도, 체력 있음, 부서지면 교체 |
| **종탑** | L2+ 원거리 투사체 자동 발사 |

### 9.2 보스 밤 (Day 5, 10, 15...)

| 보스 | 특징 |
|------|------|
| 거대 서리 좀비 | 체력·물리 공격 |
| 언데드 겨울기사 | 근접 + 방패, 동료 타겟 유도 |
| 얼어붙은 거인 | 광역 얼음 브레스, 건물 파괴 특화 |
| 서리 리치 | 원거리 스킬, 좀비 소환, 건물 우선 타겟 |

### 9.3 초대형 눈보라 밤 (7~15일 랜덤)

**사전 경고**: 전날 낮 "차가운 바람이 거세진다" + 동물 소멸. 저녁 전환 시 종탑 종소리 3타 + 30초 카운트다운.

**효과**:
- 일반 좀비 수 2배 + 네임드 보스
- **체온 시스템 활성화**: 모닥불 반경 밖 초당 지속 대미지
- 시야 추가 50% 감소 (화이트아웃)
- 바리게이트 내구도 감소 (추위)

**생존 보상**: 마을 번영도 보너스, 희귀 재료, 메타 해금 포인트 대량

## 10. 전투 & 장비 시스템

### 10.1 하이브리드 구조

| 층 | 영속성 | 획득 |
|----|--------|------|
| 기본 장비 (무기·방어구·부적) | 영속 (마을 창고) | 대장간 제작, 드랍 |
| 런타임 룬/축복 | 해당 밤에만 | 낮 설원 수집, 밤 레벨업 선택 |
| 진화 무기 | 밤 내 일시 | 기본 무기 + 룬 조건 자동 진화 |

### 10.2 기본 무기 (6종)

| 무기 | 공격 패턴 | 특징 |
|------|---------|------|
| 롱소드 | 전방 휘두르기 | 균형, 초보 친화 |
| 창 | 전방 길게 찌르기 | 긴 사정거리, 관통 |
| 활 | 자동 조준 원거리 | 사거리 최장, 근거리 약함 |
| 서리 지팡이 | 광역 냉기 장판 | 슬로우 + 광역 |
| 워해머 | 강한 근접 슬램 | 기절, 저공속 |
| 쌍단검 | 고공속 근접 | 치명타 의존 |

### 10.3 룬/축복 (밤 한정)

- 좀비 처치 경험치 → 레벨업 → 3개 중 1개 선택
- 밤 종료 시 리셋
- 낮에 룬 조각 수집 → 밤 룬 풀 가중치 부여

### 10.4 진화 무기 (밤 내)

- 기본 무기 + 특정 룬 2~3개 + 최대 레벨 → 자동 진화
- 예: 롱소드 + 연속베기 룬 + 화염 룬 = **염화 폭풍검**
- 밤 종료 시 해제 (기본 무기만 영속)

### 10.5 대미지 계산

```
최종 대미지 = 기본 공격력
  × (1 + 룬 공격 증강 합)
  × (1 + 진화 보너스)
  × 크리티컬 배율
  × 약점/저항 배율
  - 적 방어력
```

시뮬 틱(30Hz) 고정 dt, RNG 시드 기반 → 재현 가능.

## 11. 마을 시스템 & 자원

### 11.1 자원 (6종)

| 자원 | 용도 | 획득 |
|------|------|------|
| 나무 | 건물·바리게이트·연료 | 벌목 |
| 돌 | 건물·벽·종탑 | 채광 |
| 철 | 장비 제작/강화 | 심경 광맥 |
| 고기 | 전투 버프, 회복, 특수 재료 | 사냥 |
| 식량 | 동료 일일 소비 (동료 1명당 1/일) | 밭, 채집 |
| 눈꽃 결정 | 인챈트·메타 해금 | 보스, 초대형 눈보라 생존 |

### 11.2 건물 (7종)

| 건물 | 풋프린트 | 용도 | 업그레이드 효과 |
|------|---------|------|--------------|
| 모닥불 | 2×2 | 디펜스 핵심, 체온/시야/버프 | 반경·DPS·연료 효율 ↑ |
| 창고 | 3×3 | 자원 저장 한도 | 100 → 1500 |
| 숙소 | 3×3 | 동료 슬롯 | 5 → 30명 |
| 대장간 | 3×3 | 장비 제작/강화/인챈트 | 레시피·한도 해금 |
| 밭 | 3×3 | 식량 생산 | 일꾼 슬롯·생산량 ↑ |
| 목책/바리게이트 거점 | 2×2 | 바리게이트 배치 권한 | 배치 수·내구도 ↑ |
| 종탑 | 2×2 | 경고 + 원거리 자동 사격 | 정확도·투사체 강화 |

### 11.3 바리게이트 (3종)

| 타입 | 비용 | HP | 효과 |
|------|------|----|----|
| 나무 바리게이트 | 나무 5 | 200 | 좀비 이동 차단, 공격 유도 |
| 돌벽 | 돌 10 | 500 | 더 튼튼 |
| 가시 함정 | 나무 3 + 철 1 | 100 | 통과 시 피해 50, 1회성 |

## 12. 동료 시스템

### 12.1 동료 타입 (주민 기반)

| 타입 | 농사 효율 | 전투 가능 무기 | 전투력 |
|------|---------|-------------|--------|
| 아저씨 (장년 남) | 100% | 검·창·활·도끼 전부 | ★★★★ |
| 아줌마 (장년 여) | 110% | 활·창·단검 | ★★★ |
| 청년 (남/여) | 90% | 전부 | ★★★★★ |
| 노인 (남/여) | 70% | 지팡이·활 (제한) | ★★ |
| 아이 (소년/소녀) | 60% | 활·투석만 (근접 불가) | ★☆ |

### 12.2 영입 흐름

설원 NPC 조우 → F키 → 대화 UI (이름·타입·기본 스탯 표시) → [영입]/[거절]

조건: 숙소 여유 슬롯 + 식량 재고 +1일분

### 12.3 스탠스 (밤 전투)

| 스탠스 | 행동 |
|--------|------|
| 따르기 | 플레이어 ~6타일 유지 |
| 사수 | 지정 지점 ~5타일 방어 |
| 공세 | 가장 가까운 적 추적 |

### 12.4 영구 사망

- HP 0 → 즉시 사망, 장비는 시체 픽업으로 회수
- 전체 동료 사기 -10
- 마을 "기억의 돌"에 이름·타입·일수·킬수·사인 영구 기록

### 12.5 사기 (Morale)

| 요인 | 변화 |
|------|------|
| 식량 부족 | -5/일 |
| 동료 사망 | -10 (전체) |
| 보스 처치 | +15 (전체) |
| 과로 | -3/일 |

효과: 80+ → 전투력 +10% / 30 미만 → 매일 5% 탈주 확률

## 13. 메타 프로그레션

### 13.1 점수 계산

```
Final Score = Days Survived × 10
            + Companions Recruited × 5
            + Bosses Killed × 50
            + Mega Blizzards Survived × 100
            + Resources Peak × 0.1
            - Companions Lost × 3
```

### 13.2 메타 통화: 기억의 조각 (Memory Shard)

- 최종 점수의 0.1% 영구 통화
- 보스 처치 +1, 초대형 눈보라 생존 +3

### 13.3 메타 해금 트리 (예시)

| 카테고리 | 예시 |
|---------|------|
| 시작 자원 | 다음 마을 시작 시 나무·돌 추가 |
| 시작 장비 | 롱소드 레벨 2로 시작 |
| 새 건물 | 예배당·망루·약초밭 L1 해금 |
| 새 룬/진화 | 고급 룬 풀 추가 |
| 외형/타이틀 | 플레이어 외형, 업적 타이틀 |

## 14. 아트 & 오디오 방향

### 14.1 아트 스타일

- **픽셀 아트, 중세 판타지 설원**
- 캐릭터: 16×24 또는 24×32픽셀
- 타일: 32×32, 팔레트 32~48색 제한
- 색조: 차가운 청록·회백색 + 모닥불/피 오렌지·빨강 대비
- 레퍼런스: Starbound, Kingdom: Two Crowns, Darkwood
- 2D 광원 셰이더 필수

### 14.2 오디오

| 구분 | 방향 |
|------|------|
| 낮 BGM | 잔잔·고독, 류트·하프·목관 |
| 밤 BGM | 어둡고 리드미컬, 보스 전용 트랙 |
| 눈보라 BGM | 불협화음·바람, 음악 최소화 |
| 시그니처 SFX | 종탑 종소리 3타 = 초대형 눈보라 신호 |

## 15. 플랫폼 및 배포

### 15.1 플랫폼 우선순위

| 우선순위 | 플랫폼 | 방식 |
|---------|--------|------|
| 1차 | 웹 (itch.io, 자체 사이트) | Phaser 3 HTML5 |
| 2차 | Steam (데스크톱) | Tauri 래핑 |
| 3차 | 모바일 (iOS/Android) | Capacitor v7 래핑 |

### 15.2 Capacitor 모바일 설정

```typescript
// capacitor.config.ts
{
  appId: 'com.stoic.snowfield',
  appName: 'Snowfield',
  webDir: 'dist',  // Vite 빌드 출력
  android: { buildOptions: { releaseType: 'APK' } },
  ios: { contentInset: 'automatic' }
}
```

```bash
# 빌드 후 모바일 동기화
npm run build
npm run cap:sync

# Android 빌드 열기
npm run cap:android

# iOS 빌드 열기
npm run cap:ios
```

## 16. 개발 마일스톤

### Phase 0 — 프로젝트 기반 (완료)
Vite + Phaser + TS 보일러플레이트, ECS 라이브러리, Tiled 파이프라인, CI

### Phase 1 — 수직 슬라이스 (진행 중)
목표: "1일 플레이 가능한 최소 게임"
- 플레이어 이동 + 근접 무기 1종 + 자동 공격
- 설원 근교 + 나무·돌·사슴
- 마을: 모닥불 + 바리게이트(나무)
- 낮→밤 전환 + 좀비 웨이브 1종

### Phase 2 — 핵심 시스템 확장
- 동료 영입 + 스탠스 3종 + 영구 사망
- 건물 7종 + L1~L3 업그레이드
- 룬 시스템 + 레벨업 + 진화 무기 2~3종

### Phase 3 — 콘텐츠 폭
- 보스 3~5종 + 초대형 눈보라
- 건물 L4~L5, 대장간 강화/인챈트
- 튜토리얼 T1~T5
- 메타 해금 트리

### Phase 4 — 폴리시 & 출시
- UI 정제, HUD 완성
- Tauri 데스크톱 빌드 + Steam 통합 (업적/리더보드)
- 한국어 + 영어 로컬라이제이션
- itch.io 웹 데모 → Steam 정식 출시

**총 예상**: 약 6~9개월 풀타임 (파트타임 9~12개월)
