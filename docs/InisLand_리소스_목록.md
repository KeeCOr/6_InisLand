최신화: 2026-10-06 KST  
기준: `Assets/Resources`, `Assets/art`, 기획서와 Unity 설정 문서

## 감사 결과

`Assets/Resources/Sprites`, `Assets/art/Sprites`, `Assets/art/Tilemaps`에는 폴더 메타데이터만 있고 실제 런타임 이미지가 없다. 따라서 현재는 플레이어·적·자원·건물·환경·HUD를 표현하는 최종 비트맵 리소스가 모두 결손 상태다. 코드·프리팹 참조가 불완전한 복원본이므로, 생성 리소스는 먼저 `Assets/art/generated`에 보관하고 Unity 임포트·참조 확인 뒤 `Resources`에 배치한다.

## 아트 방향

- 2D 탑다운 설원 생존 어드벤처
- 차가운 청회색 설원과 주황색 난방 불빛의 대비
- 읽기 쉬운 실루엣, 과도하게 사실적인 묘사 금지
- 외부 게임·브랜드·캐릭터를 모방하지 않는 오리지널 스타일

## 파일명 규칙

- 생성 초안: `Assets/art/generated/<group>/<name>-v1.png`
- Unity 확정본: `Assets/Resources/Sprites/<group>/<name>.png`
- 스프라이트 시트는 `<name>_sheet.png`, 프레임 크기는 임포트 노트에 기록한다.
- 기존 파일은 덮어쓰지 않고 버전 번호를 올린다.

## 검수 순서

1. 설원 타일과 모닥불을 배치해 낮·밤 대비가 충분한지 확인한다.
2. 플레이어·적·자원 실루엣이 1배 확대 없이 구별되는지 확인한다.
3. Unity에서 Sprite Mode, Pixels Per Unit, 필터, 정렬 레이어를 지정한다.
4. 프리팹과 씬에서 참조한 뒤 `.meta`와 실제 런타임 표시를 확인한다.
5. 확인 전 리소스는 후보 상태로 유지하며 출시 완료로 기록하지 않는다.
